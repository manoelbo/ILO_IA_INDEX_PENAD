# Codex Final Review

## Purpose

This directory contains the independent final audit of the dissertation,
the current replication package, and the decision record for a refreshed
empirical round. The review prioritizes material correctness,
identification, reproducibility, and claim-to-output consistency. Minor
stylistic improvements are non-blocking unless they prevent circulation.

## Review rules

1. V1 is immutable after its byte-level freeze.
2. Audit agents do not edit author code or prose.
3. Statistical significance never selects the preferred specification.
4. A longer post-period measures persistence; it does not repair
   identification or weak pre-trends.
5. Dissertation structure remains unchanged.
6. No full V2 build starts until the data-vintage and storage gates pass.
