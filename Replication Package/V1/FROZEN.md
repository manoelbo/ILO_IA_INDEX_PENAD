# V1 Frozen Baseline

Frozen on 25 July 2026.

V1 is the immutable baseline replication package for the dissertation's
Sections 3–5. It reproduces the published descriptive artifacts, national
models, event studies, heterogeneity outputs, and occupation-case extensions
from the frozen analytic inputs distributed with the package.

The package contract and dry-run were revalidated after the directory move,
and the complete V1 test suite passed from this directory.

Known data-construction, econometric, and artifact-contract limitations are
documented in:

`../../Final Review/Combined/01_AUDITORIA_CODIGO.md`

Those limitations are intentionally preserved here for baseline comparison.
They are corrected only in V2. No existing V1 file may be edited after this
freeze.
