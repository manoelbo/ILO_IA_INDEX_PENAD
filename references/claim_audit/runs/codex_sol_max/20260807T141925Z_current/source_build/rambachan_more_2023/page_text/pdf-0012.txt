                       3. INFERENCE USING MOMENT INEQUALITIES
In this section, we introduce a general approach for inference that has good asymptotic properties
over a large class of possible restrictions . We show that inference on the partially identified
parameter θ = l  τ post in this setting is equivalent to testing a system of moment inequalities
with a potentially large number of nuisance parameters that enter the moments linearly. We
consider an implementation based on the conditional approach developed in ARP, which allows
us to obtain computationally tractable confidence sets with desirable power properties for many
parameter configurations.
