3.1 Estimation

Although most empirical studies use the log-linear form of the constant-elasticity model,
some authors (see Frankel and Wei, 1993, for an example in the international trade liter-
ature) have estimated multiplicative models using non-linear least squares (NLS), which
is an asymptotically valid estimator for (6). However, the NLS estimator can be very
ineﬃcient in this context as it ignores the heteroskedasticity that, as discussed before, is
characteristic of this type of model.
