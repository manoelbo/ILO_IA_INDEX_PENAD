IV.B. Using Composite DOT Variables
     Though we view the selected task measures as the most
appropriate available from the DOT, we are sensitive to the
concern that the choice of variables could be viewed as arbitrary.
One way to test their appropriateness is to use alternative com-
posite variables. We used principal components analyses (PCA) to
pool variation from each selected DOT task measure with several
other plausible alternatives and estimated equation (13) using
these composites.20 The details of our compositing exercise are
