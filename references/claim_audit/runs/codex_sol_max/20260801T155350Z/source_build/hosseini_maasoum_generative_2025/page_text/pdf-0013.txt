Under cost minimization, there exists a threshold x̂ such that juniors perform all tasks

    GenAI affects the production technology through two channels. First, task displace-
ment: GenAI automates all tasks x ∈ [0, α] for some exogenous threshold α ∈ (0, x̂ ), re-
moving them from human labor; automated tasks remain in the CES aggregator and are
performed by GenAI at exogenous unit cost c A ( x ) < w J /γ J ( x ) for x ∈ [0, α].13 Second,
within-task augmentation: on tasks that remain human-performed, GenAI augments pro-
ductivity to γ̃k ( x ) = (1 + δk ) · γk ( x ), where δ J ≥ δS ≥ 0 captures the experimental finding
that GenAI disproportionately increases the productivity of less-experienced workers.14
